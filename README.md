# YouTube Clone

A responsive YouTube-inspired website built with HTML, CSS, and JavaScript.

This project recreates core parts of the YouTube interface, including a responsive homepage, video playback, search, recommendations, comments, and interactive video controls.

## Features

- Responsive desktop and mobile layouts
- Video search by title and channel
- Collapsible sidebar
- Dynamic video cards generated with JavaScript
- Individual watch pages
- HTML5 video playback
- Recommended videos
- Subscribe button
- Like and dislike controls
- Save button
- Comment posting
- Responsive mobile watch page

## Technologies

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- Google Material Symbols

## What I Learned

Building this project helped me practice responsive web design, DOM manipulation, event listeners, JavaScript arrays and objects, dynamic HTML generation, URL parameters, and organizing a multi-page frontend project.
